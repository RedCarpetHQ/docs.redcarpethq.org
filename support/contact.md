## What to Include

### For Support Requests

**Required Information:**
- Your wallet address
- Transaction hash (if applicable)
- Campaign/token address (if applicable)
- Detailed description of issue
- Screenshots (if helpful)
- Browser and wallet used

**Example:**
```
Subject: Cannot claim dividend

Wallet: 0x742d35Cc6634C0532925a3b844Bc9e7595f0bEb
Token: 0x123...
Round ID: 3
Error: "Transaction failed"
Screenshot: [attached]
Browser: Chrome 120
Wallet: MetaMask 11.5
```

### For Screening Applications

**Required Information:**
- Full name
- Production company (if applicable)
- Wallet address
- Project synopsis
- Previous work (IMDb links)
- Budget and timeline
- Supporting documents

See [Screening Process](../getting-started/screening-process.md) for details.

### For Security Reports

**Required Information:**
- Vulnerability description
- Steps to reproduce
- Potential impact
- Suggested fix (if known)
- Your contact info (for bounty)

**Please:**
- ✅ Report privately first
- ✅ Give us time to fix
- ✅ Don't exploit vulnerabilities
- ❌ Don't disclose publicly before fix
